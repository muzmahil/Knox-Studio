# Knox Studio Setup Görselleri (Installer Assets)

Bu klasördeki görselleri dilediğiniz gibi değiştirebilir veya düzenleyebilirsiniz. Kurulum programı (setup.exe) derlenirken buradaki görselleri otomatik olarak kullanır.

## Görsel Dosyaları ve Önerilen Boyutlar:

1. **logo_badge.png**
   - **Konum:** Kurulum penceresinin sol üst köşesindeki marka rozeti / logo alanı (Social Club stili).
   - **Önerilen Boyut:** 240x60 piksel (Saydam / Transparent PNG).

2. **background.png**
   - **Konum:** Kurulum penceresinin tam ekran arka plan görseli / teması.
   - **Önerilen Boyut:** 800x520 piksel veya daha yüksek çözünürlük (PNG veya JPG).

3. **hero_art.png**
   - **Konum:** Kurulum penceresinin sağ tarafındaki büyük görsel / albüm / karakter / stüdyo görseli alanı.
   - **Önerilen Boyut:** 320x360 piksel (PNG veya JPG).

İstediğiniz görselleri bu isimlerle buraya attığınızda, `build.bat` ile derlenen yeni setup.exe sizin görsellerinizle açılacaktır.
